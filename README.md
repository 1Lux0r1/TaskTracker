# TaskTracker

Приложение для проектного управления — замена ведению проектов в Excel-таблицах.

## Документация

- [Экраны MVP](docs/ui/mvp-screens.md) — интерфейс первой версии: список проектов,
  таблица задач, доска, карточка задачи, сроки, «мои задачи». Там же — граница MVP
  и запрос к модели данных.
- [Переезд с Excel](docs/migration/excel-import.md) — карта колонок, разбор дат,
  статусов и людей, что не переносится и что с этим делать, мастер импорта в 4 шага.

Статус: проектирование. Кода пока нет.
