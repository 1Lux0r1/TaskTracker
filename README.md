# TaskTracker

Приложение для проектного управления — замена ведению проектов в Excel.

## Документация

- [Архитектура и стек](docs/architecture.md) — что и на чём строим, какие
  решения приняты по умолчанию и что сознательно не берём.
- [Модель данных](docs/data-model.md) — сущности, связи, индексы.
- [Технический план MVP](docs/mvp-plan.md) — этапы, критерий готовности,
  открытые вопросы.

Исполняемая модель данных — [`prisma/schema.prisma`](prisma/schema.prisma),
первая миграция — [`prisma/migrations`](prisma/migrations).

## Статус

Проектирование. Схема данных проверена на PostgreSQL 16, приложение ещё не
реализовано — работа начинается с этапа 0 плана MVP.
