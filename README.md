# TaskTracker

Система ведения проекта: переписка ЭДО, задачи по трекам, подписание
юридически значимых документов, график интеграций с контрагентами и отчётность
руководству. Заменяет набор рабочих таблиц Excel, которые команда ведёт рядом
с Jira.

первая миграция — [`prisma/migrations`](prisma/migrations).

## Отношение к Jira

Производственный трек остаётся в Jira: система хранит ключ задачи и
подтягивает её статус. Своими задачами ведутся официальный и юридический
треки, которых в Jira нет. Связь необязательная — модель выдержит и полный
уход из Jira.

## Статус

Проектирование. Схема из 29 таблиц проверена на PostgreSQL 16, приложение ещё
не реализовано — работа начинается с этапа 0 плана MVP.

## Данные

Рабочие файлы заказчика в репозиторий не попадают: в них служебная переписка и
персональные данные. Разбор в `docs/excel-analysis.md` описывает только
структуру.
